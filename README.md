# TapHap

TapHap is a music-based internal-clock trainer. It lets a person tap with an
audible groove, removes the audio while the underlying timeline continues, and
then reveals how steadily the person held the pulse when the music returns.

The core exercise requires no BPM entry, microphone access, song recognition,
account, or network connection.

## Project status

TapHap is in product-definition and feasibility planning. There is no app
implementation yet, and implementation must not begin until the repository
owner explicitly approves it.

The current product direction supersedes the earlier multi-device synchronized
metronome, peer-to-peer networking, and automatic song-listening concepts.
